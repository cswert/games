Available Games
Appease the Algorithm : A game about guessing the "most optimal" settings for a youtube video
Capture the Flag : Find all the flags before the bombs
Disappeading Pictionary : You know what can make pictionary more fun? If it slowly deletes itself over time
Frame Prefect : Don't play this, it sucks
Guess My Colour : Try to guess the colour based off the wavelength, RGB, and optionally HSL
Loud O Meter : Louder = funnier, or at least while it is within the target range
Pixel Racers : Top down 2D racer, shrink to a pixel in size the faster you go
Toboggan Quest : This was a request from my coworker, blame them that this abomination exists
Ultimate TicTacToe : Tic tac toe within a bigger tic tac toe, but with a few twists
Wiki Bingo : Complete a bingo board from the various wikis (wikiHow, wikipedia, fandom)
Word Games : Word search on a changing board, and word ladders with various modes
